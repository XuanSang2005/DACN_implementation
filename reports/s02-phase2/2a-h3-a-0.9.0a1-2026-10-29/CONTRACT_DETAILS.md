# H3-A private contracts — chi tiết được cụ thể hóa cho audit implementation

Căn cứ [draft.2](../../../docs/S02_2A_H3_E1_HISTORY_DESIGN_PROPOSAL.md) §2.3/§5.1 và D1–D5 đã được người dùng chấp thuận. Đây là field/type/counter concretization trong H3-A, không đổi canonical schemas/registry/A1/A2 hoặc cấp quyền loader/writer. [API](../../../docs/S02_2A_H3_A_IMPLEMENTATION.md), [source definitions](../../../packages/s02/src/dacn_s02/h3_contracts.py) và schema copies từ installed delivery wheel ở `delivery/private-contracts/INDEX.json` trong evidence external.

| Contract | Chi tiết cụ thể đã chọn |
| --- | --- |
| Config | Một closed object có profile/contract/rules pins E1; private marker/version/handler/policy/limits; store/session/command/parent/reserved Run/time; mode/step/units/goal; current source/archive/base IDs+hashes; optional anchor; parent_metadata null ở root adopt, Admission ở step/revalidate; typed aliases; candidate pin nullable theo mode, analysis required; historical_reviews_pin/history_binding/authority_binding/intent hash |
| Mode | Adopt step0/toàn family inventory/goal admission, candidate null; step1–4 goal build/candidate required; revalidate step1–4 goal admission hoặc retained_output/candidate null. Không reinterpret command H2 hoặc tự tạo schema defaults |
| Intent | Exclude speculative reserved_run_id/started_at/intent_sha256 và input StageRef allocations khi so logical intent; giữ command/store/session/parent/source/pair/raw lengths+SHA/versions/limits/anchor/history/authority/review pins. Sealed/persisted bytes vẫn phải exact; A chỉ hash/compare data |
| Plan | Closed bindings/allocation/batch/promotions/admission/outcome/diagnostics; exactly one reserved Run; allowed types chỉ Run/Artifact/Model/Change/Issue/AS; no new human evaluation/provider attempts; exact staged-input promotions + plan promotion, exact projected graph Records và sealed plan Artifact hash. Adopt không Model/Change/Issue mutation; no-head không domain records |
| Admission | Full obligations row/source/assessment/Parts/Issue context; all-current selectors, TaskOrigin/GuardOrigin, progress/retained assessments, current/history IssueRoles, A2 transition summaries/proof record SHA, full hold reasons. Dữ liệu phải đối chiếu actual proposed graph, không chỉ shape/hash |
| History | Profile/owner/operation inventory SHA; explicit Record/Event/Snapshot/archive pins; key→current Issue ID map; registry pin. Whole detached store checked qua canonical validators, không “trusted operational lookup” |
| Registry/ReviewsPin | Exact protocol §2.3: raw UTF-8 JSON required; invoker path/expected SHA/registry/store IDs; sorted required Issue IDs và exact sorted entries; reviewer/assessment/canonical dependency SHA. Tính pin raw/required/reviews hashes; R toàn store/fixed, no self-derived fallback |
| Authority/Binding | Closed exact local/synthetic control approvals allow/deny; normalized binding có full base/source/history/anchor/current selectors/progress/raw/request/review pins. Không wildcard/default allow. Trust context ngoài work và ngoài historical lane; registry không thay semantic approval |
| Analysis | `s02-h3-analysis/0.1.0-draft.2`: source_context_id/snapshot_id/base_pair/selectors_sha256/unit_ids; inspections mỗi obligation/criterion (`source_ref,read,verdict,basis_source_refs,needed_facts,reason`); independence mỗi Issue-key/unit (`verdict,basis_source_refs,reason`). Full inventory/code checks, không human verdict mới |
| Anchor/Progress | Actual finalized publisher/promoted plan/hash/Run pair; ordered transitions với per-transition hashes; typed element/Part/row/Issue correspondence và context hashes; output unit/stage/origin/raw/source/alias refs. Stage chỉ từ provenance kiểm được, không Model appearance. Retained progress không tự tăng stage; no-anchor giữ actual IDs unassessed. `admit` không nhận free-form progress dict |
| Task/Guard origins | Verify code provenance/root/current lineage/actual promoted plan/raw/predicate. Existing H2 task predicates là all_mapping/unit_mapping/unit_responsibility; existing H2 guard predicate merge_assessment và key derived từ origin command. Role string/kind/prefix tự khai không miễn blocker; guard provenance không resolve guard. New H3 writers/predicates cần scope B/C riêng |

Các scalar metadata integer dùng exact int/finite integral Decimal; bool không là int. Arrays/set refs phải unique nơi contract quy định; raw bytes/hash giữ exact, không reorder criteria/workflow. Current refs và history refs được walk bằng schema x-history, không generic recursive model_id replacement; projection chỉ trả body, không có Record ID/time allocation.

D5 concretization: cùng caps numeric H2 và Budget30s; registry≤1MiB. Count current-issue map key+value và alias key+referenced ID; total reference occurrences của external trust tuple/registry/data/plans/configs trong invocation, không unique-ID counting hoặc reset theo unit. Chain supersedes/from dùng cùng depth64 trước recursive canonical checks. Shape/schema export không là deployment/publication token; runtime safety B/C §7.1 vẫn chưa được kiểm bởi pure A.

Không phát hiện nhu cầu đổi semantics đã chốt trong draft.2 để làm các API này. Nếu audit implementation yêu cầu delta contract, tạo đợt sửa có diff/evidence riêng; không sửa snapshots/handoff/design audit đã seal. Các private closed definitions và cách đếm này là đối tượng auditor kiểm, chưa tự gắn trạng thái được audit code/nghiệm thu.
